# Telangana Tracker

A civic accountability site tracking Telangana government promises and
performance for citizens: promise status, district map, party comparison,
and citizen reporting.

## State

Dormant since 2026-04-24, parked mid-rebrand from a party-focused tracker to
a neutral civic site. The planning docs are the most complete part: see
PLAN.md, ABOUT.md, DATA-SOURCES.md, HOW-IT-WORKS.md, and the SPEC-*.md files.

## Stack

Next.js App Router, TypeScript, Tailwind.

## Running

```bash
npm install
npm run dev
```

See LOG.md for founder status.
